# Quokka

**Exploring compact multimodal intelligence for local devices.**

Quokka is a research project investigating how model compression affects useful capability, memory use, and inference speed. The aim is to evaluate text, vision, and tool use together under practical deployment constraints.

## Status

Early development. There is no runnable model or application release yet, and no benchmark results are claimed.

The first milestone is a reproducible local baseline, followed by a measured comparison with a compressed model. Results will report both capability and deployment costs, including model size, peak memory, and latency.
